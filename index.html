03 / 09 · Industrial computer vision

From floc video to a binary operator cue

A desktop prototype joined underwater video, morphology, geometric features, and XGBoost.

Industrial Digitalization Engineer · 2025 Beijing Zhongke Shengtai

Problem

Turn subjective floc inspection into a visible, testable cue

The GUI exposed the original frame, processed mask, parameters, and two classifiers side by side.

Pipeline

  • Grayscale → median filter → adaptive threshold → morphology.
  • Connected components → five geometric features → threshold or XGBoost.
  • Python, OpenCV, NumPy, scikit-learn, XGBoost, and Tkinter.

Reported result

88.5% floc-level test accuracy for the binary XGBoost classifier; the résumé’s 89% is the rounded value. The same document reports 67.4% for a fixed threshold.

Needs review: 2,270 labeled images were expanded into 258,887 floc records before a random stratified split. Temporal/video independence and plant generalization were not tested. The archived model is binary (“good / add more”); the résumé’s five dose steps remain a separate, unresolved claim.

05 / 09 · HIT capstone

Path planning with delayed observations

A simulated study of reward design and stale observations in dynamic navigation.

B.Eng. capstone · 2023—24 HIT · Electrical Engineering

Question

Can a DQN planner stay useful when the observation arrives late?

The simulation varied stale observations while comparing reward logic and network variants.

Method

  • Main/target networks with replay memory and randomized observation delay.
  • Reward terms for path progress, collision avoidance, and convergence.
  • Fifteen repeated runs averaged on the supplied results slide.

Reported result

98.1% versus 92.6% success is +5.5 percentage points (+5.9% relative); mean path length was 29.113 versus 30.852.

Needs review: values are transcribed from the capstone slide. Raw logs, confidence intervals, simulator details, and a real-robot evaluation are not available.
